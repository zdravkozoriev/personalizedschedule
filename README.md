# Графикът ми

Личен планер за работни и лични задачи, направен за телефон. Работи без интернет и без акаунт. Всички данни се пазят само на устройството.

## Какво може

- **Задачи:** списък с всички работни и лични задачи (продължителност, приоритет, бележки).
- **Подзадачи:** всяка задача може да има подзадачи. В графика се виждат под задачата и се отмятат поотделно за всяко изпълнение. Когато всички са готови, задачата се отбелязва като свършена.
- **Категории:** всеки раздел има свои категории (напр. „Обаждания“, „Имейли“). Когато маркираш раздел в „Задачи“, под него се изброяват категориите му; докосни категория, за да видиш задачите в нея.
- **Раздели:** задачите се групират в твои раздели (напр. „Клиент А“, „Здраве“, „Дом“), всеки със свой цвят. В графика, седмицата и прегледите задачите се показват в цвета на раздела си.
- **Повтарящи се задачи:** всеки ден, в делнични дни, в избрани дни от седмицата или веднъж месечно. Влизат в графика сами, по желание в определен час. Пропуснатите не се трупат.
- **Ден (time blocking):** часова скала. Докосваш празно място и слагаш задача в този час. Лента показва колко е планирано спрямо реалния ти капацитет и предупреждава при претоварен ден.
- **Седмица и месец:** преглед на натовареността по дни (превключват се горе в раздел „Седмица“).
- **Вечерен преглед:** след 19:00 (настройва се) приложението напомня да решиш какво става с несвършеното: свърших, утре, друг ден или отпада.
- **Седмичен преглед в понеделник:** статистика за миналата седмица, недовършените задачи, 3 фокуса за седмицата, разпределяне на задачите без дата и натовареност по дни.
- **Място:** всяка задача може да има локация. Вижда се в графика и се отваря в Карти с едно докосване.
- **Гласови команди:** бутонът с микрофона приема команди на български, например:
  - „Добави среща с Иван утре в 10 в офиса за час“
  - „Фитнес всеки понеделник и четвъртък в 18 и 30“
  - „Свърших разходката“ / „Премести отчета за петък в 11“
  - „В списък Пазар мляко“ / „Бележка паролата за Wi-Fi е на рутера“

  Преди изпълнение приложението показва какво е разбрало, за да потвърдиш. Разпознаването на говор изисква интернет. Ако браузърът не го поддържа, можеш да диктуваш с микрофона на клавиатурата в полето за команда.
- **Бележки:** важни бележки като свободен текст или списък с отметки. Отметнатите точки отиват най-долу, а най-важните бележки се маркират със ⭐ и стоят най-горе. Бележките могат да се слагат в същите раздели като задачите и да се филтрират по тях.
- **Резервно копие:** сваляне и възстановяване на данните като файл (в „Преглед“ → „Настройки“).

## Публикуване (еднократно)

1. В GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. Всяко качване в основния клон публикува приложението чрез `.github/workflows/pages.yml` на `https://zdravkozoriev.github.io/personalizedschedule/`. Ръчно: **Actions → Публикуване в GitHub Pages → Run workflow**.

> GitHub Pages за **частни** хранилища изисква платен план (GitHub Pro). Ако хранилището е частно и нямаш Pro, направи го публично. Данните ти не са в хранилището, а само на телефона, така че кодът може спокойно да е публичен.

## Инсталиране на телефона

- **iPhone (Safari):** отвори адреса → бутон „Сподели“ → „Добави към началния екран“.
- **Android (Chrome):** отвори адреса → менюто ⋮ → „Инсталирай приложението“ / „Добави към началния екран“.

След това се отваря като обикновено приложение, на цял екран и без интернет.

## Важно за данните

Данните се пазят в паметта на браузъра на телефона. Ако изтриеш данните на браузъра или приложението, те се губят. Затова **сваляй резервно копие** от време на време.

## Локално стартиране

```bash
python3 -m http.server 8000
# отвори http://localhost:8000
```

## Стартиране на компютъра с Docker (Windows)

1. Инсталирай [Docker Desktop](https://www.docker.com/products/docker-desktop/) и го стартирай. Остави режима **Linux containers** (по подразбиране).
2. Изтегли кода: в GitHub натисни **Code → Download ZIP** и разархивирай (или `git clone`).
3. Отвори PowerShell в папката и изпълни:
   ```powershell
   docker compose up -d --build
   ```
4. Отвори http://localhost:8080 в Chrome или Edge. С иконата за инсталиране в адресната лента приложението става отделна програма.

Контейнерът тръгва автоматично заедно с Docker Desktop. След обновяване на кода изпълни отново `docker compose up -d --build`. Спиране: `docker compose down`.

> Този вариант е само за компютъра. Телефонът не може да го ползва (няма HTTPS), а данните на компютъра и телефона са отделни.
