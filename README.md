# Графикът ми

Личен планер за работни и лични задачи, направен за телефон. Работи без интернет и без акаунт. Всички данни се пазят само на устройството.

## Какво може

- **Задачи:** списък с всички работни и лични задачи (продължителност, приоритет, бележки).
- **Повтарящи се задачи:** всеки ден, в делнични дни, в избрани дни от седмицата или веднъж месечно. Влизат в графика сами, по желание в определен час. Пропуснатите не се трупат.
- **Ден (time blocking):** часова скала. Докосваш празно място и слагаш задача в този час. Лента показва колко е планирано спрямо реалния ти капацитет и предупреждава при претоварен ден.
- **Седмица и месец:** преглед на натовареността по дни.
- **Вечерен преглед:** след 19:00 (настройва се) приложението напомня да решиш какво става с несвършеното: свърших, утре, друг ден или отпада.
- **Седмичен преглед в понеделник:** статистика за миналата седмица, недовършените задачи, 3 фокуса за седмицата, разпределяне на задачите без дата и натовареност по дни.
- **Резервно копие:** сваляне и възстановяване на данните като файл (в „Преглед“ → „Настройки“).

## Публикуване (еднократно)

1. В GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. Слей промените в клон `main`. Работният процес `.github/workflows/pages.yml` публикува приложението на `https://<потребител>.github.io/personalizedschedule/`.

> GitHub Pages за **частни** хранилища изисква платен план (GitHub Pro). Ако хранилището е частно и нямаш Pro, направи го публично. Данните ти не са в хранилището, а само на телефона, така че кодът може спокойно да е публичен.

## Инсталиране на телефона

- **iPhone (Safari):** отвори адреса → бутон „Сподели“ → „Добави към началния екран“.
- **Android (Chrome):** отвори адреса → менюто ⋮ → „Инсталирай приложението“ / „Добави към началния екран“.

След това се отваря като обикновено приложение, на цял екран и без интернет.

## Важно за данните

Данните се пазят в паметта на браузъра на телефона. Ако изтриеш данните на браузъра или приложението, те се губят. Затова **сваляй резервно копие** от време на време.

## Локално стартиране

```bash
python3 -m http.server 8000
# отвори http://localhost:8000
```
